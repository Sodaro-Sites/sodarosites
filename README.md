# Sodaro Sites — old address

Sodaro Sites now lives at https://sodaro-sites.github.io/ (repo `Sodaro-Sites/sodaro-sites.github.io`).

This repo only keeps the old address `https://sodaro-sites.github.io/sodarosites/` working:

- Every old page forwards straight to the same page at the new address, keeping any `?package=` or `#demo` part of the link.
- Any other old link (for example `/sodarosites/packages`) forwards to the same path on the new site, through `404.html`.
- `assets/` is a copy of the new site's assets, so old links to images such as the share picture still work.

Make site changes in `sodaro-sites.github.io`, not here.
